# FlowBoard 

A modern, high-performance project management dashboard built with React, Vite, and Tailwind CSS. Designed to streamline task tracking with dynamic multi-column workflows and secure context-based authentication.

## Tech Stack
- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **State Management:** React Context API

## Features
- **Secure Authentication:** Context-driven login flow with protected routing.
- **Dynamic Kanban Board:** Interactive task management across multiple workflow columns.
- **Responsive UI:** Clean, modern interface optimized for all screen sizes.
